RUN N RUMBLE - YOUR OWN MUSIC
=============================
1. Drop MP3 files into this folder with these exact names:

     title.mp3    - title / menu / victory screens
     level1.mp3   - Level 1 (Green Hills)
     level2.mp3   - Level 2 (Cloud Kingdom)
     level3.mp3   - Level 3 (Secret Garden)

2. List the ones you added in music.json, for example:

     { "tracks": ["title", "level1", "level2", "level3"] }

Tracks loop. Any track not listed uses the built-in tune.
The mute button (speaker icon, top right) mutes music and sound effects.
