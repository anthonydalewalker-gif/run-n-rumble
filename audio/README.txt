RUN N RUMBLE - YOUR OWN MUSIC
=============================
Drop MP3 files into this folder with these exact names and the game uses
them automatically instead of the built-in placeholder music:

  title.mp3    - title / menu screens
  level1.mp3   - Level 1 (Green Hills)
  level2.mp3   - Level 2 (Cloud Kingdom)   [when it's built]
  level3.mp3   - Level 3 (Secret Garden)   [when it's built]

Tracks loop. If a file is missing, the built-in tune plays instead.
The mute button (speaker icon, top right) mutes both music and sound effects.
